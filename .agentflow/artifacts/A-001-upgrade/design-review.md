## A：可靠貼上契約

- 錄音開始建立目標快照。包含 PID、視窗、可用欄位身分及選取範圍。未知值不得推定相同。

- 注入目標讀取器、剪貼簿及事件送出器。測試不得改一般剪貼簿或使用者編輯器。

- 每次交易持有識別碼及寫入後的 `changeCount`。只有版本及所有權仍相符，才還原原快照，包括原本空剪貼簿。

- 序列化須涵蓋還原等待期。排隊任務送出前仍須重查目標、取消狀態及安全輸入。

- 目標改變或無法確認時保留文字，提供明確「複製」按鈕。不得先把結果寫入剪貼簿。

- 安全欄位不自動貼上或複製。權限不足時提供輔助使用設定入口。

- 結果區分事件已送出、僅複製、取消、失敗。事件已送出不等於目標已接收；送出後不得重試。

- 驗收：新複製內容不被還原覆蓋、連續交易不交叉還原、切換 App／欄位／選取範圍阻擋、權限不足提示可操作。

## B：任務與救援契約

- 單次任務包含 UUID、階段、目標、模型、語言、開始時間與增益紀錄。所有延遲閉包與回呼先核對 UUID。

- 階段包含錄音、辨識、整理、等待輸入、完成、失敗、取消。終態只能寫入一次。

- Esc 同時涵蓋本機及全域事件。取消先使任務失效，再停止錄音、預覽、原生辨識、整理及 Python 工作程序。

- Python 程序終止回呼也需識別程序世代。舊程序結束不得清掉新程序的管線或請求。

- 一般辨識採 120 秒，整理採 10 秒。首次模型準備獨立顯示，不得悄悄沿用 600 秒辨識等待。

- 原文必須在整理前進入共同流程。原生與 Python 均使用同一流程，避免失去原文或整理兩次。

- 歷史新增欄位使用明確 `decodeIfPresent` 預設。儲存採原子寫入，避免中斷破壞所有歷史。

- 救援只保留辨識失敗的本機錄音。預設 24 小時、10 筆、200 MB，超出任一限制便依時間清理。

- 救援資料夾限擁有者存取，檔案限擁有者讀寫。保存相對識別碼，限制刪除與重試在指定資料夾內。

- 啟動、加入資料及關閉保存時執行清理。取消與成功辨識刪錄音；貼上失敗只留文字。

- 歷史重試建立新任務，沒有舊貼上目標。結果只供檢視及手動複製。

- 驗收：晚到成功不得貼上；重複完成只處理一次；當機及逾時可救援；舊 JSON、重啟清理及關閉保存均有效。

## C：模型就緒契約

- 狀態區分未安裝、下載中、驗證中、可用、需要修復。磁碟大小只能顯示容量。

- 遠端來源需固定提交版本，並取得可信來源的檔案大小與雜湊。不能把下載後自行計算的值稱為可信來源證明。

- 下載與轉換在暫存目錄完成。必要檔案、來源驗證與實際載入通過後，才發布就緒標記並替換。

- Breeze 轉換紀錄來源版本、參數與工具版本。現行 `strict=False` 載入不能單獨證明完整性；需檢查必要權重及設定。

- 就緒標記記錄產物指紋。啟動檢查檔案變動；未變動不重複昂貴載入。內容雜湊驗證與載入驗證是兩件事。

- Swift 與 Python 使用同一份規格。仍依 8-bit、FP16、遠端順序選擇，但每個候選都須符合可用條件。

- 修復先保留最後可用產物。驗證失敗不得覆蓋它。舊產物首次驗證可重新建立標記。

- 驗收：中斷下載、缺權重、內容損壞、過期標記、失敗修復、正常重啟各有測試。

## D：輸入增益契約

- 持久化 −6 至 +12 dB、每格 3 dB、預設 0 dB。設定只影響 App，不改系統音量。

- 在 WAV、預覽與音量顯示之前處理一次。使用實際聲道布局，包含交錯格式，不假定第一聲道代表全部。

- 係數為 `10^(dB/20)`。0 dB 有效樣本不變；非有限值需安全處理。增益後限制有效範圍並計算削波比例。

- 使用可重用空間，避免每個回呼大量配置。變更從下一音訊區塊生效；歷史記錄初值及變更值，避免錯稱整段固定增益。

- 削波門檻屬初始政策，需在實作紀錄明列。提示只要求降低增益，不宣稱辨識已改善。

- 驗收：0、+6、+12 dB，負增益，多聲道、交錯、空區塊、NaN、無限值及削波；確認 WAV 與預覽使用同一處理結果。

- 品質評測另記 60 段來源與場景。無真實語料或麥克風證據時，只交付增益功能，不宣稱改善氣音。

## E：個人詞彙與整理契約

- 新規則另存版本化資料。包含識別碼、錯詞、正詞、啟用、來源歷史及確認資訊。舊提示詞不改寫。

- 從歷史人工建立規則，提供啟用、刪除與撤銷。中文邊界不明時，保存前要求明確確認。

- 對原輸入掃描一次。遇重疊取最長符合；輸出片段不再投入替換，確保 A→B 不接著變 C。

- 英文採完整詞邊界。大小寫政策需明列並測試；數字、中英混排及重疊規則也需測試。

- 統一順序為原文、確認規則替換、選用標點整理、檢查、交付。保存原文、替換結果與整理結果。

- 整理檢查保留詞彙、數字、否定及原有語義符號。不能用「刪除全部標點後相同」判定安全，否則小數點及負號可能改義。

- 空白、控制標記、詞彙改動、失敗與超時皆回退整理前文字。可複製或還原原文。

- 驗收：不連鎖、邊界與大小寫、刪除及撤銷、數字／否定修改、整理不可用仍完成。
